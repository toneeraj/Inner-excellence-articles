# Inner-excellence-articles

Articles related to inner excellence book and learnings.

Each piece takes a passage from a teacher and works it against a stretch of an
ordinary day. The passage is the fixed part. The writing around it gets
re-rendered as the practice changes shape, so a piece carries both the date it
was first sent and the revision shape it currently stands in.

## Conventions

Posts live in `posts/`, named `YYYY-MM-DD-<pillar>-<slug>.md`, dated by when the
piece was first sent rather than when it was last re-rendered. Front matter
carries `title`, `pillar`, `originally_sent`, `re_rendered`, `revision_shape`,
and `sources`.

The layout is flat on purpose. One piece is one instance, and one instance is
not yet evidence of a shape — no pillar directories, no tagging scheme, no site
build until a second piece shows what actually varies between them. The index
table above is the only abstraction here, and it is cheap to restructure when
the time comes.

## Re-rendering

A re-rendered piece is an edit to the existing file, not a new one. Update
`re_rendered` and `revision_shape` in the front matter and let git hold the
earlier version — the history is the record of how the practice moved.
